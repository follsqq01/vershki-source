# Вершки

Лендинг о совместном творчестве с бабушками и дедушками.

## Запуск

Сайт написан на HTML, CSS и JavaScript, без сборщика и зависимостей.

```sh
python3 -m http.server 4177
```

Откройте http://localhost:4177.

## Структура

- `index.html` — семантические секции, тексты и FAQ (`details` / `summary`).
- `style.css` — адаптивная вёрстка, сообщения, бусины, градиенты, карточки и декоративные круги.
- `landing.js` — заголовки из букв.
- `quiz.html`, `quiz.css`, `quiz.js` — тест из семи вопросов с множественным выбором, сбросом при возвращении на страницу и подбором трёх занятий.
- `quiz-data.js` — 24 занятия из предоставленного файла.
- `page-transition.css` — переход между страницами через View Transitions, где поддерживается браузером.
- `motion.js` / `motion.css` — объёмная орбита карточек, наклон и свет от курсора, частицы, появления и сцена переписки.
- `hero-spin.js` — общая круговая карусель бусин «ВЕРШКИ» и исходной звезды.
- `media.js` — медиатека профиля, аудиоплееры и диалог просмотра фотографий/видео.
- `assets/` — локальные шрифты, фотографии и сложные декоративные элементы из Figma.

Исходный макет: https://www.figma.com/design/uiCMBMRpnhpHVA1eeVsQZj/Untitled?node-id=0-228

Desktop-композиция следует макету шириной 1512 px. До 700 px разделы перестраиваются в колонку. Простые формы и интерфейс выполнены HTML/CSS; скриншотов страницы в реализации нет.

Кнопка «перейти» открывает `quiz.html`. Подбор учитывает интересы, место, максимальные выбранные время и бюджет. Если точных совпадений недостаточно, карточки явно показывают отклонения. Ответы хранятся в памяти страницы; при повторном входе и возврате через историю тест начинается заново. Фотокарточки заполнены демонстрационными фото. Медиатека содержит фото, синтетические голосовые и видеокружочки; источники — в `assets/media/CREDITS.md`. Ответы FAQ добавлены как редактируемый текст.

Оригинальный первый экран с анимацией сохранён в первом коммите `4699fbb`.

## Публикация

GitHub Pages: ветка `main`, корень репозитория (`/`). Файл `.nojekyll` включает публикацию статических файлов без Jekyll.

## Анимация и доступность

Секция после фотографий закрепляется на время вертикальной прокрутки и показывает непрерывную композицию 4734 × 760 из нового макета Figma (`xOZCeyhkEqWQbzR2EpMtdp`, узел `1:140`); после её конца обычная прокрутка продолжается. 28 отдельных графических слоёв экспортированы в прозрачные PNG 2× и преобразованы в WebP, текст остаётся HTML. Координаты и исходные ID сохранены в `assets/story/layout.json`.

Восемь карточек закреплены на одном большом круговом колесе с центром ниже блока: видна только верхняя дуга. При наведении всё колесо плавно останавливается, выбранная карточка наклоняется к курсору, а световой блик следует за указателем. Колесо можно перетаскивать мышью или пальцем; после перетаскивания фото не открывается случайно. Стрелки влево/вправо на сфокусированной карточке поворачивают колесо. На телефоне карточки открываются касанием. Кнопка паузы останавливает декоративное движение.

При первом входе в переписку запускается сцена на 11,1 секунды: сообщения, голосовое, затем реакция. На время сцены прокрутка страницы удерживается; «Пропустить», Escape, изменение размера окна и завершение сцены всегда освобождают прокрутку. Повтор запускается вручную. При `prefers-reduced-motion` сцена показывается сразу, без блокировки.

Во вкладке «аудио» находятся демонстрационные голосовые.

Первый экран — одно кольцо: шесть бусин «в е р ш к и» чередуются с цветными фигурами, включая исходную плоскую звезду, и движутся влево по окружности. Буквы сохраняют вертикальное положение. Фигуры остаются непрозрачными и уходят за границы первого экрана по окружности; возвращаются только на скрытой нижней части цикла. При наведении движение приостанавливается. Декоративные формы — звезда, сердце, цветок, ромб, капля и бант. Перетаскивание и прокрутка колёсика над фигурами вращают кольцо; стрелки управляют кольцом, Home возвращает начало. При reduced-motion автоматическое движение отключено.

Медиатека поддерживает клавиатуру, паузу и перемотку; одновременно играет только один файл. Диалог закрывается Escape и возвращает фокус. Звук не запускается автоматически.

Обновление: первый экран использует девять пользовательских WebP из `assets/hero/` в числовом порядке. Исходники сохранены в папке «первый экран». У горизонтальной истории родитель использует overflow: clip для работы sticky. Медиатека профиля имеет автоматическую высоту без внутреннего скролла.

Бусины первого экрана движутся без остановки при наведении со скоростью 0.075 радиана/с. Восстановлена круговая нить позади бусин. На результатах теста есть ссылка «на главную».

На мобильных горизонтальная история и приглашение «А что для вас» занимают один закреплённый экран 100svh: верхняя композиция движется при прокрутке, нижний блок остаётся на месте. На широком экране приглашение идёт отдельной секцией.
