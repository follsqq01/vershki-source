# Вершки

Лендинг о совместном творчестве с бабушками и дедушками.

## Запуск

Сайт написан на HTML, CSS и JavaScript, без сборщика и зависимостей.

```sh
python3 -m http.server 4177
```

Откройте http://localhost:4177.

## Структура

- `index.html` — семантические секции, тексты и FAQ (`details` / `summary`).
- `style.css` — адаптивная вёрстка, сообщения, бусины, градиенты, карточки и декоративные круги.
- `landing.js` — заголовки из букв и уведомление о будущем тесте.
- `motion.js` / `motion.css` — объёмная орбита карточек, наклон и свет от курсора, частицы, появления и сцена переписки.
- `hero-spin.js` — общая круговая карусель бусин «ВЕРШКИ» и исходной звезды.
- `media.js` — медиатека профиля, аудиоплееры и диалог просмотра фотографий/видео.
- `assets/` — локальные шрифты, фотографии и сложные декоративные элементы из Figma.

Исходный макет: https://www.figma.com/design/uiCMBMRpnhpHVA1eeVsQZj/Untitled?node-id=0-228

Desktop-композиция следует макету шириной 1512 px. До 700 px разделы перестраиваются в колонку. Простые формы и интерфейс выполнены HTML/CSS; скриншотов страницы в реализации нет.

Тест пока не реализован по просьбе владельца. Кнопка показывает «Тест скоро появится». Фотокарточки заполнены демонстрационными фото. Медиатека содержит фото, синтетические голосовые и видеокружочки; источники — в `assets/media/CREDITS.md`. Ответы FAQ добавлены как редактируемый текст.

Оригинальный первый экран с анимацией сохранён в первом коммите `4699fbb`.

## Публикация

GitHub Pages: ветка `main`, корень репозитория (`/`). Файл `.nojekyll` включает публикацию статических файлов без Jekyll.

## Анимация и доступность

Восемь карточек закреплены на одном большом круговом колесе с центром ниже блока: видна только верхняя дуга. При наведении всё колесо плавно останавливается, выбранная карточка наклоняется к курсору, а световой блик следует за указателем. Колесо можно перетаскивать мышью или пальцем; после перетаскивания фото не открывается случайно. Стрелки влево/вправо на сфокусированной карточке поворачивают колесо. На телефоне карточки открываются касанием. Кнопка паузы останавливает декоративное движение.

При первом входе в переписку запускается сцена на 11,1 секунды: сообщения, голосовое, затем реакция. На время сцены прокрутка страницы удерживается; «Пропустить», Escape, изменение размера окна и завершение сцены всегда освобождают прокрутку. Повтор запускается вручную. При `prefers-reduced-motion` сцена показывается сразу, без блокировки.

Во вкладках «аудио» и «голосовые» находятся демонстрационные голосовые.

Первый экран — одно кольцо: шесть бусин «в е р ш к и» чередуются с цветными фигурами, включая исходную плоскую звезду, и движутся влево по окружности. Одновременно видны максимум три элемента; буквы сохраняют вертикальное положение. Перетаскивание вращает кольцо с затухающей инерцией; стрелки управляют кольцом, Home возвращает начало. При reduced-motion автоматическое движение отключено.

Медиатека поддерживает клавиатуру, паузу и перемотку; одновременно играет только один файл. Диалог закрывается Escape и возвращает фокус. Звук не запускается автоматически.
